# Запуск gremu: ключи и ручные шаги владельца

Разработчик не может сделать эти шаги за вас: они требуют аккаунтов, договоров или решений магазина. Пока ключа нет, функция честно показывает «не подключено» и ничего не имитирует.

## 1. Production-ключи и настройки

| # | Что | Где взять | Переменные | Обязательно для запуска |
|---|---|---|---|---|
| 1 | База PostgreSQL | Supabase / Neon / хостинг | `DATABASE_URL` | **да** |
| 2 | Секрет приложения | `openssl rand -base64 48` | `APP_SECRET` | **да** |
| 3 | Адрес сайта (https) | ваш домен | `APP_URL` | **да** |
| 4 | Google OAuth client | Google Cloud Console | `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` | да (вход, кабинет) |
| 5 | Почта сотрудников-админов | — | `ADMIN_EMAILS`, `STAFF_EMAILS` | да (админка через Google) |
| 6 | Пароль владельца (резерв) | `npm run admin:hash -- "…"` | `ADMIN_USERNAME`, `ADMIN_PASSWORD_HASH` | рекомендуется |
| 7 | Почтовый провайдер | resend.com + подтверждённый домен | `EMAIL_PROVIDER=resend`, `EMAIL_API_KEY`, `EMAIL_FROM` | да (письма менеджеру) |
| 8 | Email менеджера | — | `MANAGER_EMAIL` | да |
| 9 | Payme: касса и ключ | бизнес-кабинет Payme после договора | `PAYME_MODE=production`, `PAYME_MERCHANT_ID`, `PAYME_SECRET_KEY` | для онлайн-оплаты |
| 10 | Gemini API key | aistudio.google.com | `GEMINI_API_KEY` | для AI-помощника |
| 11 | Click | после договора с Click | `CLICK_*` | нет (адаптер ещё не реализован) |

В production **не задавайте** `AUTH_DEV_LOGIN` и `CATALOG_SEED_DEMO`. Первый в production и так игнорируется.

## 2. Настройки во внешних кабинетах

- [ ] **Google Cloud → OAuth client:**
  - redirect URI `https://<домен>/api/auth/google/callback`;
  - origin `https://<домен>`;
  - OAuth consent screen опубликован (выведен из Testing).
- [ ] **Resend:** домен отправителя подтверждён (SPF/DKIM). Отправьте тестовое обращение с сайта и убедитесь, что письмо пришло.
- [ ] **Payme, касса:**
  - Endpoint `https://<домен>/api/payments/payme`, поле счёта `order_id`;
  - пройдите сценарии песочницы и сверьте формат ссылки оплаты (см. docs/PAYMENTS.md);
  - сделайте одну реальную оплату на минимальную сумму и верните её.
- [ ] **Gemini:** ключ ограничен Generative Language API, в Google Cloud задан лимит расходов.

## 3. Данные, которые должен дать магазин

Сейчас на сайте честные заглушки («появится после подтверждения»). Ничего не выдумано.

- [ ] **Каталог:** реальные товары, цены, остатки и совместимость. Загружаются через «Админка → Товары → Импорт CSV» (или вручную). Демо-товары в production не создаются.
- [ ] **Логотип:** файл логотипа (сейчас вместо него текстовый Wordmark).
- [ ] **Контакты:** телефон, адрес, часы работы, Telegram/Instagram. Это страница «Связаться» и подвал.
- [ ] **Доставка:** способы, регионы, стоимость, сроки, пункт самовывоза. Заполняется в `src/config/shop.ts` (`DELIVERY_METHODS`) и `src/content/info-pages.ts`.
- [ ] **Оплата и возврат:** условия возврата и гарантии. Это `src/content/info-pages.ts`.
- [ ] **Фискализация Payme:** коды ИКПУ, `package_code` и ставки НДС по товарам. Их даёт бухгалтерия, после этого добавляется `detail` в чек (см. docs/PAYMENTS.md).
- [ ] **Политика конфиденциальности** и согласие на обработку данных: юридический текст.

## 4. Перед открытием

- [ ] `npm run check`: typecheck, lint и тесты зелёные.
- [ ] `npm run build` без ошибок; сайт открывается по https.
- [ ] Пробный путь на production без оплаты: поиск → товар → корзина → заказ → письмо менеджеру → заказ виден в админке.
- [ ] Вход через Google на production; кабинет; заказ виден в «Мои заказы».
- [ ] Сотрудник из `STAFF_EMAILS` входит в админку и не видит «Каталог» и «Журнал».
- [ ] Резервное копирование базы включено у провайдера.
- [ ] Если хостинг масштабируется на несколько инстансов, лимиты запросов нужно перевести на Redis/Upstash: сейчас они в памяти процесса.

## 5. Что сознательно не сделано (следующие шаги)

| Что | Почему | Приоритет по TASKS |
|---|---|---|
| Избранное и сравнение товаров | отложено как P1 | P1 |
| Адаптер Click | нет договора и тестовых данных; интерфейс готов | P1 |
| Фото детали в форме подбора | нужно файловое хранилище (S3/Supabase Storage) | — |
| Сохранение выбранного авто для гостя | у вошедших есть «Мои автомобили»; для гостей не сделано | P0-дополнение |
| Полная Content-Security-Policy для скриптов | нужен nonce для inline-скриптов Next.js | улучшение |
| Позиции фискального чека Payme (`detail`) | нужны коды ИКПУ от бухгалтерии | до production-оплаты |
| Поиск по каталогу через SQL | сейчас фильтрация в памяти, хватит на несколько тысяч товаров | при росте каталога |
